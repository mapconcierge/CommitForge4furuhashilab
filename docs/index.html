メンバー別 総合活動スコア ランキング

コミット・PR・Issue・レビューに加え、新規リポジトリ作成・フォーク上を含む活動リポジトリ数・獲得スター/フォークを重み付けして合算した独自スコア（降順ソート）。 重みは config/members.yaml の scoring で調整可能。GitHub公式の指標ではない点に注意。

メンバー コミット プルリクエスト Issue レビュー 新規リポジトリ 活動リポジトリ 獲得スター 獲得フォーク 総合スコア

データソース: GitHub GraphQL API（各アカウントの公開 contribution 情報）。 集計対象アカウントは config/members.yaml で管理しています。

数値は各メンバーの GitHub 上での公開活動を機械的に集計した参考値であり、研究・開発への貢献度そのものを表すものではありません（非公開リポジトリでの作業、コードレビュー以外の貢献、Issue起票以外の議論などは反映されません）。成績等の判断材料として単独で用いる場合はご注意ください。

「総合活動スコア」は本リポジトリ独自の重み付けヒューリスティックであり、GitHub が公式に定義・公開している評価指標ではありません。コミット・PR・Issue・レビューに加えて、GitHubの公式contribution集計が基本的に対象外とする「フォーク上での自主的な開発」を補う指標として新規リポジトリ作成数・push実績のあるリポジトリ数（フォーク含む）、および獲得スター・フォーク数（対数スケール）を加点しています。重みの根拠と各項目の限界は config/members.yaml に明記しています。
